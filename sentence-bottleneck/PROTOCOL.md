# Budgeted sentence evidence for a fixed local reader

The previous cross-corpus experiment improved document recall but gave an uncertain answer gain. The new, prospective comparison holds the retrieved article set fixed and measures whether a compact representation lets the same reader answer without processing the full context. It separates support selection from answer generation.

Use the same verified HotpotQA distractor corpus and title-component split. Exclude all 200 groups from the prior study, including its engineering smoke. Use the next 1,400 groups for supervised sentence ranking, the next 160 for development, and the next 256 for the paired evaluation. Retain one deterministic question per group. The supervised target consists of the corpus's sentence-support labels. Candidate documents for every arm are the frozen reveal-bridge selections. Every arm reads the same candidate set upstream, so savings describe downstream model input only.

Compare (i) complete retrieved articles, (ii) a linear support estimator ranking sentences independently, and (iii) the same estimator followed by pair-first selection that rewards two high-scoring sentences from different articles and shared distinctive terms. Both compact methods use the same exact cap over additional input tokens, tokenizer and evidence format. Select the shared cap from 192, 256 and 320 tokens on development data using the independent estimator, favoring the smallest cap attaining at least 92% of its support-sentence recall at 320. Select the pair link weight from 0, 0.25 and 0.5 on development using complete support-sentence coverage, breaking ties by recall then the smaller coefficient. No answer generation or QA scores enter fitting or selection. The evaluation uses the identical quantized local Qwen3-1.7B reader, prompt and greedy decoding across arms.

The primary outcome is F1 of the pair-first compact arm relative to full retrieved context. Claim a substantial compression result only if its percentile paired 95% lower bound is above −4 F1 points and the measured average prompt token reduction is at least 40%. A four-point margin is a prespecified engineering tolerance for this reader and benchmark, with the exact trade-off disclosed. A positive F1 improvement requires a lower endpoint above zero. Secondary pair-first versus independent compact measures whether bridge structure contributes above a strong control at the same cap. Report sentence and article coverage, exact match, prompt length, output length, and uncertainty. No selective filtering of test questions or outcome-based changes. One process and one active local generation. Publish the scoring ledger without raw text or weights.

Prior work compares extractive support detection and context compression for question answering. This small experiment tests supervised selection and calibrated budgets with frozen retrieval and generation, not a new state-of-the-art benchmark model.
