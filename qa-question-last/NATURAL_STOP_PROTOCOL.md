# Matched answer prefixes before natural stopping

Test the published HotpotQA-trained question-last Qwen3-1.7B adapter against its frozen base on the same 169 MuSiQue transfer groups and disjoint 160-group replication used in the exact-length experiment. Preserve the exact question-last prompt IDs within every pair. Use the saved adapter bytes and previously screened cohorts. The current checkpoint and prompts have been evaluated on these panels, while this natural-stop equal-length analysis is new.

Use ordinary greedy decoding with the model's configured EOS IDs and a common 24-token cap. Record the entire emitted token sequence and the terminal condition for each reader. Omit EOS itself from the answer sequence. Keep the final ordinary token if the decoder reaches the cap. No token masking, forcing, or answer-padding occurs. Verify shared-cache execution against ordinary generation on earlier HotpotQA development prompts. Use one loaded model and one active sequence.

For each question, choose the shorter of the two pre-EOS answer lengths. Score the entire prefix of exactly that many tokenizer IDs for each reader. Keep caps and zero-length prefixes in the evaluation. A cap is a censored observation of stopping time. Decode the slice before applying official MuSiQue normalization and maximum over the released aliases. Keep all decoded prefix text in the primary metric, including any answer labels or line breaks. This defines the score at the latest observed matched prefix before either reader stops. Generation itself may run longer for one reader, so this tests equal **scored** length.

Require an estimated gain of at least three answer-F1 points and a positive lower endpoint of a paired 95% percentile interval with 20,000 support-component resamples on the primary 169 groups. Apply the same criterion separately on the 160 disjoint groups, and report the pooled estimate with resampling stratified by panel. Report the matched-length distribution, generated counts, EOS/cap counts, exact match and wins/ties/losses.

As prespecified diagnostics, also score both full natural responses and equal prefixes ending before the earlier first completed nonblank answer line. In the line test, exclude the entire token that introduces a line break ending a nonblank line, including a token that also contains text. Decode cumulative prefixes to detect this boundary. Report an EOS-ended-pairs-only sensitivity separately. The shorter natural length and EOS availability depend on the models' outputs, so these comparisons describe paired scored prefixes rather than an externally assigned inference budget. See the preceding forced-length study for that fixed-budget test.
